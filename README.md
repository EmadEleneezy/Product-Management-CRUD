# Product Management CRUD System

A simple product management system built using HTML, CSS, and JavaScript.

## Features

- Add new products.
- Display and manage product information.
- Update existing products.
- Delete products.
- Search for products.
- Responsive and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start managing your products.
